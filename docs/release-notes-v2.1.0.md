What's New:

🕰️ Clock Styles: One **Clock** block, many looks — Flip, Text, LCD, Dot Matrix, Nixie tubes, three analog faces and Rings. Pick a style from preview tiles; the inspector only shows the settings that style actually uses.

⏳ Progress Style: The seconds bar is now a clock style. Show the minute, hour or day as a bar, ring or dots, ticking smoothly or step by step.

🔤 Text Styles for Every Block: Date, weather, text and calendar blocks can use the Flip, LCD, Dot Matrix and Nixie looks too — set once, like the font.

📅 Calendar: Add Google, Outlook or iCloud calendars via their secret ICS link under **Data › Calendar** (buttons take you straight to the right settings page, no login needed). A new calendar block shows today's or upcoming events with filters.

📍 Weather Location Search: Type a city and pick it from suggestions, see a live weather preview, and get a short confirmation when it's saved.

🖱️ Smarter Drag & Drop: Drop on a block's edge to slide in beside it, on its top or bottom edge for a new row; the middle still groups. Full rows make room by shrinking, and groups can stack vertically.

📐 Cleaner Spacing: No more hidden space around text — padding 0 really means 0. Every block has horizontal and vertical padding, rows size themselves to their tallest block, and gaps and row alignment live in one place under **Whole clock › Spacing**. Column widths are dragged right on the canvas (double-click to reset).

🧰 Tidier Editor: Collapsible inspector sections, background settings under Look, a resizable inspector you can widen by dragging, a size slider that stops where the content stops growing, and saved layouts with real clock thumbnails.

🎨 Icon Styles: Choose colored emoji or flat line icons per block.

🌍 English & German: The settings window now speaks both.

⬆️ Upgrading from 2.0: Nothing to do. Fliq converts your layout and saved layouts once on the first start. Row heights and single gaps between specific rows are replaced by the new spacing model, so rows may sit a little tighter — give them air with the block padding if needed.

📦 Quick Install (Fedora):
```
sudo dnf install https://github.com/Dav1d-Fn/Fliq-Desktop-Flipclock/releases/download/v2.1.0/Fliq-2.1.0-1.x86_64.rpm
```
