# README media and showreel

Scripts that record the GIFs in `docs/media/` and render the Fliq showreel from the real UI.
They drive the Vite dev server in headless Chromium; nothing touches your mouse or keyboard.

- `lib.mjs`: the browser setup. It seeds the settings (layout, cached weather, a fixed time
  shortly before 10:00 so the cards flip to the full hour), stands in for the Tauri IPC and
  draws a mouse cursor. It has two recorders: a real-time screenshot loop for the GIFs, and a
  stepped one for the showreel. The stepped recorder moves the page's fake clock 1/30 s per
  frame and screenshots at 2x, so the clips are smooth and sharp however slow a screenshot is.
- `record.mjs`: the scenes. `hero`, `add`, `group`, `inspector`, `grid` and `stills` are for
  the README GIFs. `reel-*` are for the showreel (clips at 2x plus transparent clock stills).
- `make-gifs.sh`: crops and converts the GIF clips into `docs/media/*.gif` and the stills.
- `reel/`: the showreel as a [Remotion](https://www.remotion.dev) composition (React), cut to
  the beat of the music (120 BPM). `timeline.ts` holds the shots on the beat grid,
  `FlipShot` the split-flap change between shots (the top half falls away, the next shot's
  bottom half falls into place, like a flip card), `scenes/` the shots and `ScreenCrop` one
  part of a recorded clip as a card. The opening flips through five looks of the clock
  (`reel-looks`) into the real clock, whose cards turn to 10:00 on the drop.
- `render-reel.sh`: records the clips if they are missing (the music has to be in `out/`). It then renders `out/fliq-showreel.mp4` (1920×1080, 30 fps, H.264 + AAC, levelled to
  −16 LUFS), the video embedded at the top of the repository README.

`out/` (clips, stills, music, renders) is not committed.

## Music: source and license

"The Glide Path", a lo-fi track with a beat, generated by David with Google Gemini (13.11.2026),
120 BPM. Under Google's terms for generative AI, Google claims no ownership of generated content;
the track carries Google's SynthID watermark. The file is not in the repository: put it at
`out/the-glide-path.mp3` before rendering. The reel plays it from 10.1 s, so its drop at 16.09 s
lands on the clock's flip at 6 s, and fades it out over the last 2.5 s. There are no sound
effects.

## Re-render

```bash
npm run dev                       # in the repo root, port 1420
cd docs/video
npm install                       # Remotion, Playwright, Inter
npx playwright install chromium   # or set CHROME=/path/to/chrome-headless-shell
./render-reel.sh                  # add --record to record the reel clips again
npx remotion studio               # optional: preview and tweak the reel in the browser
```

The render runs at low priority with four workers, so the desktop stays usable.

For the README GIFs:

```bash
node record.mjs hero add group inspector grid stills
./make-gifs.sh
```

Scenes and timings follow the current UI (selectors like `.block-tile`, `.resize-handle.right`
and the inspector's slider labels). The reel's crops are in CSS px of the 1280×800 settings
window (`reel/scenes/FeatureScenes.tsx`). When the editor changes, check the clips frame by
frame before replacing anything.
